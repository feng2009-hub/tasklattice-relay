## Landing request-flow product marks

The animated request-flow diagram uses compact transparent marks solely to
identify concrete implementations. The monochrome vector paths for
`claude-code-mark.png`, `github-mark.png`, `jira-mark.png`,
`confluence-mark.png`, `postgresql-mark.png`, `nvidia-mark.png`, and
`anthropic-mark.png` come from the repository's installed Simple Icons
`16.27.1` package. They are colorized for legibility on the dark diagram.

- Claude Code catalog: https://simpleicons.org/?q=claude%20code
- GitHub MCP server: https://github.com/github/github-mcp-server
- Atlassian Rovo MCP server (Jira and Confluence): https://github.com/atlassian/atlassian-mcp-server
- PostgreSQL / pgvector: https://github.com/pgvector/pgvector
- NVIDIA NeMo Guardrails: https://github.com/NVIDIA-NeMo/Guardrails
- Anthropic: https://www.anthropic.com/

`mem0-mark.png` is derived from the official Mem0 dashboard favicon:
https://github.com/mem0ai/mem0/blob/main/server/dashboard/public/favicon-32x32.png

`litellm-train.png` is a transparent crop of the train medallion in LiteLLM's
official proxy wordmark:
https://github.com/BerriAI/litellm/blob/main/litellm/proxy/logo.jpg

All marks remain trademarks of their respective owners. Their inclusion does
not imply endorsement or partnership.
