# 智能体开发者指南

构建并维护自己负责的智能体，组合已批准的能力，并在交付前验证实际运行行为。

## 构建智能体

1. **从智能体花园开始。** 选择符合任务的专业方向或已登记智能体，并确认负责人、支持的运行时和所需能力。[打开专业智能体](/__project__/agent-garden)。
2. **组合已批准的能力。** 选择已发布的技能、MCP 连接、知识源、记忆、模型路由和策略。不要在提示词中写入提供商或服务凭证。[打开 MCP 连接](/__project__/mcp-servers)。
3. **创建并观察实例。** 创建运行时，跟踪状态变化，并通过日志区分期望配置与实际健康状态。[打开运行时实例](/__project__/instances)。

## 交付前验证

- **测试最小有效路径。** 执行一个有代表性的交互，验证工具和数据边界，并确认非特权用户也能理解失败反馈。[打开实例交互](/__project__/instances)。
- **检查追踪和日志。** 使用运行时日志检查创建过程和进程健康；在权限允许时，使用追踪记录理解执行耗时以及模型或工具行为。[打开追踪记录](/__project__/traces)。
- **记录交接信息。** 写明目标用户、支持的任务、数据边界、已知故障模式以及后续维护负责人。

> **开发者权限随资源归属变化。** 创建和修改权限适用于自己拥有或维护的智能体。项目级目录可能可读，但无关智能体及其他用户会话不在权限范围内。终端执行仅限管理员。
