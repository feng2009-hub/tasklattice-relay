# 普通用户指南

使用分配给自己的智能体，让每次交互保持在设计用途内，并用有价值的上下文报告异常。

## 使用已分配的智能体

1. **确认项目与智能体。** 先在项目切换器中确认当前项目，再打开运行时实例。你只能使用分配给自己的智能体。[打开运行时实例](/__project__/instances)。
2. **检查用途与数据边界。** 开始前阅读智能体说明和使用指引。除非获批场景明确允许，否则不要提交密钥或个人数据。
3. **开始或继续自己的会话。** 描述清晰任务、检查输出，并在产生重要后果的操作前确认。你的会话权限不包括其他用户的会话。[打开实例交互](/__project__/instances)。
4. **报告问题。** 记录时间、智能体名称、任务、可见错误，以及重试是否改变结果。不要把凭证或敏感提示内容复制到工单中。

> **分配关系就是访问边界。** 普通用户可以查看和使用分配给自己的智能体，并参与自己的会话；不能管理智能体配置、项目资源、策略或其他成员。
