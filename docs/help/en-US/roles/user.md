# User guide

Work with Agents assigned to you, keep each interaction within its intended purpose, and report unexpected behavior with useful context.

## Use an assigned Agent

1. **Confirm the Project and Agent.** Use the Project switcher, then open Runtime Instances. You will only be able to work with Agents assigned to you. [Open Runtime Instances](/__project__/instances).
2. **Check purpose and data boundary.** Read the Agent description and instructions before starting. Do not submit secrets or personal data unless the approved use case explicitly allows it.
3. **Start or continue your session.** Send a clear task, inspect the result, and confirm consequential actions before they occur. Your session access does not extend to other users' sessions. [Open Instance interaction](/__project__/instances).
4. **Report a problem.** Capture the time, Agent name, task, visible error, and whether retrying changed the result. Do not copy credentials or sensitive prompt content into a ticket.

> **Assignment is the access boundary.** The User role can view and interact with assigned Agents and participate in its own sessions. It does not manage Agent configuration, Project resources, policies, or other members.
