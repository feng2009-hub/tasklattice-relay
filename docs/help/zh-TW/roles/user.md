# 一般使用者指南

使用指派給自己的 Agent，讓每次互動都維持在設計用途內，並以有用的內容回報異常。

## 使用已指派的 Agent

1. **確認專案與 Agent。** 先在專案切換器中確認目前專案，再開啟執行個體。你只能使用指派給自己的 Agent。[開啟執行個體](/__project__/instances)。
2. **檢查用途與資料邊界。** 開始前閱讀 Agent 說明與使用指引。除非經核准的情境明確允許，否則請勿提交金鑰或個人資料。
3. **開始或繼續自己的工作階段。** 清楚描述任務、檢查輸出，並在可能產生重要後果的操作前再次確認。你的工作階段權限不包含其他使用者的工作階段。[開啟執行個體互動](/__project__/instances)。
4. **回報問題。** 記錄時間、Agent 名稱、任務、可見錯誤，以及重試是否改變結果。請勿將憑證或敏感提示內容複製到問題單中。

> **指派關係就是存取邊界。** 一般使用者可以查看並使用指派給自己的 Agent，也可以參與自己的工作階段；但不能管理 Agent 設定、專案資源、原則或其他成員。
