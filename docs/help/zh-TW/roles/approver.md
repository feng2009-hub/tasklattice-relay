# 核准者指南

獨立審查受治理的變更、核對請求範圍，並始終區分核准決策與實際執行。

## 審查請求

1. **確認請求人與目標。** 確認由誰提出變更、會影響哪一項專案資源，並確保自己獨立於請求人與目標操作人員。[開啟請求預覽](/__project__/requests)。
2. **評估證據。** 比較業務理由、請求限制、原則影響、風險、可復原性，以及能夠滿足需求的最小範圍。
3. **記錄有明確邊界的決策。** 說明理由後核准、拒絕或要求修改。核准決策不代表變更已實際套用。
4. **另外驗證執行結果。** 已核准的變更由負責的服務或操作人員執行後，再透過保留的證據確認實際結果。[開啟稽核日誌](/__project__/audit-logs)。

> **核准工作區目前是預覽功能。** 角色與能力模型已經存在，但請求介面尚未連接持久化的決策與執行 API。預覽操作不是正式核准，也不會套用任何變更。
