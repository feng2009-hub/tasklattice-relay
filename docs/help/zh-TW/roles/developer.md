# Agent 開發人員指南

建置並維護自己負責的 Agent、組合已核准的能力，並在交付前驗證實際執行行為。

## 建置 Agent

1. **從 Agent 廣場開始。** 選擇符合任務的專業方向或已登錄的 Agent，並確認負責人、支援的執行階段與所需能力。[開啟專家 Agent](/__project__/agent-garden)。
2. **組合已核准的能力。** 選擇已發布的技能、MCP 連線、知識來源、記憶、模型路由與原則。請勿在提示詞中寫入提供者或服務憑證。[開啟 MCP 連線](/__project__/mcp-servers)。
3. **建立並觀察執行個體。** 建立執行階段、追蹤狀態變化，並透過日誌區分預期設定與實際健康狀態。[開啟執行個體](/__project__/instances)。

## 交付前驗證

- **測試最小有效路徑。** 執行一次具代表性的互動、驗證工具與資料邊界，並確認非特權使用者也能理解失敗回饋。[開啟執行個體互動](/__project__/instances)。
- **檢查追蹤與日誌。** 使用執行階段日誌檢查建立過程與程序健康狀態；權限允許時，使用追蹤記錄瞭解執行時間以及模型或工具行為。[開啟追蹤記錄](/__project__/traces)。
- **記錄交接資訊。** 清楚記錄目標使用者、支援的任務、資料邊界、已知故障模式，以及後續維護負責人。

> **開發人員權限會隨資源歸屬而變化。** 建立與修改權限適用於自己擁有或維護的 Agent。專案層級目錄可能可供讀取，但無關的 Agent 與其他使用者工作階段不在權限範圍內。終端執行僅限管理員。
